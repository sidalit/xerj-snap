## Getting Started

<a href="https://snapcraft.io/xerj"><img alt="Get it from the Snap Store" src="https://snapcraft.io/en/dark/install.svg" width="180"></a>

```bash
sudo snap install xerj
xerj --data-dir ~/xerj-data
```

Keep the server running. In another terminal, index and search a project:

```bash
export XERJ_API_KEY="$(cat ~/xerj-data/admin.key)"
xerj autoindex ~/my-project
xerj search "your search terms"
```

The server listens on localhost with authentication enabled. Open the console setup URL printed at startup.

## Configure

This snap has no `snap set` options. Use `xerj --help` for application settings, and keep the server data directory outside the folders you index.

For MCP, configure command `/snap/bin/xerj`, arguments `["mcp"]` and environment `XERJ_AUTH="ApiKey YOUR_KEY"` against the running server.

```bash
sudo snap connect xerj:removable-media   # optional: /media, /mnt
```

Model downloads, corpus caches and settings live under `~/snap/xerj/common`.

## Limitations

- Files must be in a non-hidden home folder or connected removable storage; hidden files directly under your home are inaccessible.
- Embeddings run on the CPU and download models on first use. The amd64 build requires an x86-64-v3 CPU.
- Replace the executable path in MCP configuration generated by `xerj init` with `/snap/bin/xerj`.
- Host SSH keys, credential helpers, browser launching and GitHub CLI integrations are unavailable. Use HTTPS corpus URLs and open the console URL yourself.

## Build

```bash
git clone https://github.com/sidalit/xerj-snap.git
cd xerj-snap
sudo snap install snapcraft --classic
snapcraft pack
```
